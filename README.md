# Скрипт для перемещения уволенных сотрудников в отдельную OU в AD

Скрипт создавался под следующий сценарий:
Устанавливается срок действия учетной записи. Обычно это увольняющийся человек. Скрипт ищет учетные записи с истекшим сроком сроком, удаляет группы доступа, добавляет группу "Уволенные", переносит email и номер телефона в другие поля ( чтобы данные не потерялись, но не попадали больше в справочники ), блокирует учетную запись и переносит ее в OU "Уволенные".

## Зависимости:

`system.directoryservices.accountmanagement`  
`microsoft.extensions.configuration`  
`microsoft.extensions.configuration.fileextensions`  
`microsoft.extensions.configuration.json`  

## Алгоритм действия скрипта:
1. При первом запуске создает папки *"log"* и *"config"* в директории,, откуда запущен.
2. Создает в папке *"config"* файл *"Config.json"* с пустыми значениями и прекращает работу.
3. При последующих запусках проверяет заполненные поля конфига и выключается, если каких-то данных нет.
4. Если конфиг заполнен, считывает данные из конфига.
5. Получает список логинов из OU указанного в конфиге.
6. По списку логинов формирует словарь в который записывает следующие данные по каждому:
	1. *cn*
	2. *accountExpires*
	3. *distinguishedName*
	4. *description*
	5. *telephoneNumber*
	6. *wWWHomePage*
	7. *mail*
	8. *homePhone*
	9. *userAccountControl*
7. Дальше по списку проверяет каждого пользователя. Если *accountExpires* меньше текущего времени, то:
	1. Переносит данные из поля *mail* в поле *wWWHomePage*
	2. Переносит данные из поля *telephoneNumber* в поле *homePhone*
	3. Добавляет в поле *description* дату переноса в *distinguishedName*
	4. Добавляет учетной записи группу, указанную в конфиге. назначает эту группу основной
	5. Удаляет остальные группы
	6. Блокирует учетную запись
	7. Переносит учетную запись в OU, указанную в конфиге

## Пример заполнение config.json:

```jsonc
{
  "ActiveDirectory": {
    "ldapPath": "OU=Example,DC=youdomain,DC=local", // Место в AD, где скрипт будет искать уволенных сотрудников  
    "ouForDesmissed": "OU=Уволенные,DC=sstkvik,DC=local", // OU, в которую будут перемещены учетные записи с истекшим сроком годности  
    "primaryGroupID": "6154", // ID группы, которая будет назначена учетной записи как основная, после удаления рабочих групп доступа  
    "distinguishedName": "CN=Dismissed,OU=Dismissed,DC=youdomain,DC=local" // Группа, которая будет указана как основная  
  }
}
